# Security policy

Report vulnerabilities privately to the maintainer (GitHub security advisories on this repository). Do not open public issues for security problems. Expect an acknowledgement within 3 working days. Severity SLAs follow the engineering standard: critical ≤ 7 days, high ≤ 30, medium ≤ 90.

In scope: approval bypass, gate/evidence forgery, policy bypass (command, path, production), secret leakage into artifacts/logs/GitHub, sandbox escape in Code Mode, hook bypass. Design and residual risks: [docs/security/threat-model.md](docs/security/threat-model.md).
